# React 19 demo

[English](./README.md) | [简体中文](./README_CN.md)

This launcher uses React 19 `createRoot` and the shared [`demo_react_shared`](../demo_react_shared/README.md) application. The shared application demonstrates nested lazy routes, a named outlet, and visible route-guard order.

```bash
npm install
npm start
```

Run `npm run build` for a production bundle. `config-overrides.js` resolves the shared source directly and applies scoped styles to each example.
